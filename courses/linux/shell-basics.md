# Navigation & Shell Basics

Welcome to your first lab. We'll start by exploring the Linux filesystem.

## Navigation Commands

- `pwd`: Print Working Directory
- `ls`: List files
- `cd`: Change directory

## Lab Task

1. Check your current directory.
2. List the root directory.
3. Move to the `/tmp` directory.

```bash
pwd
ls /
cd /tmp
pwd
```

## Validation

Run the validation below to confirm you moved to the `/tmp` directory.

```verify
pwd
/tmp
```
