  * Yazılım geliştiriciler için docker kullanımı

  * Kurumunuzda Docker kullanmanın yapabileceği faydalar

Mac üzerinde docker çalıştırabilmek için [buradan](https://docs.docker.com/docker-for-mac/install/) faydalanabilirsiniz.

Linux sunucular üzerinde docker kurmak için [buradan](https://docs.docker.com/engine/install/ubuntu/) faydalanabilirsiniz.
